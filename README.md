# DevLaunch Portfolio Website

A clean, modern, and mobile-responsive personal portfolio website built from scratch using semantic HTML5 and custom CSS3. 

---

## ✨ Features
* **Semantic Structure:** Built using modern HTML5 layout tags (`<header>`, `<main>`, `<section>`, `<footer>`).
* **Custom Styling:** Features a clean, card-based UI layout with custom accent borders and typography.
* **Modern Forms & Tables:** Styled interactive contact form inputs and responsive data tables.
* **Flexbox Navigation:** A clean, horizontal navigation bar that transforms into a vertical menu on mobile devices.
* **100% Mobile Responsive:** Optimized with CSS Media Queries to look perfect on phones, tablets, and desktops.

---

## Technologies Used
* **HTML5:** Page structure, content grouping, forms, and data tables.
* **CSS3:** Custom layouts, modern typography, Flexbox grids, and responsive breakpoints.
* **Netlify:** Automated cloud hosting and deployment pipeline.

During this project, I mastered the frontend fundamentals:
1. Connecting external style sheets to HTML documents.
2. Troubleshooting browser cache issues and debugging CSS class specificity.
3. Overriding browser defaults using a global CSS universal reset (`*`).
4. Setting up a professional continuous deployment pipeline via cloud hosting.

## How to Run This Project Locally
1. Clone or download this folder to your machine.
2. Open the folder inside **VS Code**.
3. Install the **Live Server** extension by Ritwick Dey.
4. Right-click `index.html` and select **Open with Live Server**.
